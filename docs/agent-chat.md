# 创作助手（第二阶段）

画布右下角打开「创作助手」，选中节点或点击「@ 引用」指定素材。输入修改要求，Enter 发送，Shift Enter 换行。助手使用控制台当前文本模型与备用路由；需要理解图片时，使用已有视觉模型路由。实际使用的模型显示在聊天面板中。

在画布或全屏媒体预览中，按 `/` 进入助手输入框，按 `⌘J` 或 `Ctrl+J` 打开或收起助手。通过快捷键从全屏预览打开助手时，该媒体版本会加入草稿。按 `A` 可在画布当前光标位置开始批注，在全屏图片中可框选区域，在全屏视频或音频中可批注当前播放时间。

在助手输入框键入 `@` 可同时搜索资产和当前画布节点。选择节点后，输入框上方会显示指定的版本，同名节点会显示各自的编号。之后切换节点的版本 Tab，已指定的引用仍沿用原版本；可以移除后重新指定。

在空白助手输入框键入 `/` 可搜索并选择创作技能，选好后继续写这条指令。提交后，输入框上方会显示送达状态和对话名。送达状态待确认时可以点「重新发送」，系统会沿用原请求编号及原先的素材版本和附件，同时保留之后修改的草稿。

空白图片、视频或音频节点上的「交给助手」会新建对话、引用该节点，并带入已有提示词草稿。发送后，普通同类生成工具会把结果写入所选节点，多个候选保存为该节点的版本。移除这项引用可取消绑定。「填写提示词」则直接聚焦节点自己的编辑框。

在画布折叠分组的素材窗口中点击「引用到创作助手」，可将该组图片、视频和音频的当前版本加入对话草稿。确认输入框上方的引用后，再发送对话。每条消息最多引用 30 个节点。

全屏预览图片、视频或音频时，点击「和助手讨论此版本」，可在预览内继续当前对话，并把正在看的版本加入草稿。切换预览版本会保留已有引用，要改用新版本可再次点击这个按钮。关闭预览后，可在画布上继续同一对话。

在创作助手的对话历史旁打开「记忆」，可以编辑个人偏好和当前项目规则。个人偏好随账号跨画布使用。项目规则由项目所有者管理，适用于该项目下的画布；移出项目后，画布会采用所在项目的规则。当前消息里的明确要求优先，其次是项目规则、个人偏好。清空对应输入框并保存即可移除记忆。

也可以在对话里说「记住，我的字幕默认用简体中文」或「记住，本项目的分镜固定 16:9」。助手会在对话中给出保存建议，点击「记住」后生效。通过资产库管理角色、场景和其他参考素材。

在「创作应用」填写需求后，可将需求带入分镜、商品套图或角色模板的副本预览。分镜模板可在预览里调整镜头数、每镜时长和画幅。动态画面和视频重制可从应用直接打开工具，并带入填写的需求及选定媒体版本。白模和制作复盘也有直接打开的入口。

例如：

- “以选中的图片为参考，生成三个暖色版本，横向排列在原图右边。”
- “第二张再顺时针旋转90度，保留之前的图片。”
- “把选中的节点顶部对齐。”
- “创建一个文本节点，写三条海报文案。”

助手可以正常讨论，也可以连续调用工具。新建素材生成独立节点；图片修改、抠图、图层调整、参数重试与视频重生成在原节点追加历史版本，通过节点右侧Tab切换，原始文件保留。操作卡片展示服务返回的阶段进度，点击结果缩略图定位节点；卡片展开后可查看结果说明。聊天窗口支持停靠、浮动、调整大小和位置记忆。

助手执行期间，可以用「新对话」在同一画布启动另一项工作。每张画布最多同时执行三个对话，可在助手顶部切换查看。对话分别保存草稿、引用版本、确认方案和进度，「停止」只停止当前对话的当前任务。多个助手要写入同一节点时，后提交的生成会提示等待。

画布顶部的「助手任务」会汇总当前账号在该画布的待处理、执行中及排队任务，并显示各对话最近一轮已结束任务。收起助手后，待处理数量仍会更新。点击一项可打开对应对话，有待确认卡时会直接定位到卡片。有已知来源或生成中的关联节点时，可点「定位节点」跳到画布位置。

面板按提交顺序逐条显示排队指令。点击一条会打开所属对话并定位到该指令，也可以直接移除尚未开跑的普通指令。同一对话中正在执行的任务和其他排队指令会继续处理。

「助手任务」会提示尚未查看的新结果。点击结果会打开对应对话并定位到那一轮的回复或操作卡，查看状态保存在当前浏览器。可以直接在面板点击「停止」，操作针对该行正在执行的任务，保留其他对话和排队指令。

「查看任务历史」按提交顺序从新到旧列出已完成、中断及停止的任务。同一对话的多轮任务会分别显示，可继续加载较早记录。点击一条记录跳到对应的回复、操作卡或原始指令。

从已完成的任务点「继续创作」，可沿用原对话和草稿。点击一个节点，或把输入框上方的任务名称拖到节点上，会引用当时的节点版本。选择画布空白处则指定新结果的放置位置。选择目标后可继续编辑指令，再发送。

在「助手任务」底部可开启任务提示音。当前画布有新结果、任务中断或需要补充和确认时会播放提示音。刷新页面后，先点击页面或按键以启用浏览器声音。节点上的任务标记可以显示状态文字或圆点。两项设置保存在当前账号使用的浏览器中。

点击节点旁的任务标记可查看当前指令和状态，并打开对话、跳到待确认卡或停止本轮。停止只作用于打开详情时选中的那一轮。若这轮在面板打开期间结束，详情会更新，后续任务继续执行。

同一对话里的消息按提交顺序执行。执行期间可以继续输入指令并点击「加入队列」，也可以从待执行列表移除指令。画布最多等待 8 条指令，有空位时优先启动等待最久且当前空闲的对话。队列保存在服务端，收起对话或刷新页面后仍会运行。开始执行时会重新读取画布，排队时明确引用的素材版本会保留。

图片、图片编辑、视频和音频生成的任务卡上，已确认失败的结果可以「按原参数重试」。批量生成只补跑失败项，使用原提示词、参考素材和生成设置。重试进度和结果显示在新卡片上，可继续编辑输入框里的草稿。当前对话空闲且画布还有并行位置时可重试。提交状态待核实的任务可在任务中心确认。

在助手面板的「生成方式」中，可为接下来提交的指令选择模式。

- **自动生成**是默认设置。助手准备好方案后直接提交。
- **智能确认**在每条指令中允许自动生成不超过两张图片。超过额度的整个图片批次，以及视频、音频和白模任务，需要确认。
- **每次确认**会在提交图片、视频、音频或白模任务前显示方案。核对数量、提示词和可用参数后，点击「确认生成」或「跳过」。等待确认时，后续指令继续排队。

支持直接调整的方案可展开「调整参数」，修改提示词或生成数量。保存参数后会显示更新后的方案，再点击「确认生成」才提交。

普通生图确认卡会列出本次采用的画布版本、资产和已定稿视角。修改提示词中的 `@` 引用后，确认卡会重新核对素材。参考资产或生成服务在等待期间变化时，请重新核对方案。

在控制台为生成服务设置费率后，画布单节点、批量确认和助手确认卡会显示预计费用。视频采用参考素材时，按实际可使用的模型、分辨率和预计时长计算。修改提示词引用会重新核算。没有匹配费率时显示暂无法估算，批量确认仍会列出可计价的部分。

通过 `@资产` 引用其中的音频或视频时，助手会按解析出的参考素材选择可用服务并核对时长。指定模型时会检查该模型能否采用这些素材。确认卡里修改引用后会重新检查。

同时使用画布连入的素材和 `@资产` 时，模型按两边合计的数量与时长校验。自动选择会按配置顺序找到满足要求的模型，确认卡会显示这次采用的模型。

生成套图时，每张图可以使用不同的场景、道具或已定稿角色视角。确认卡按图列出采用的资产，用户在对话中明确指定的引用继续生效。若确认期间参考资产被更新，请重新核对套图后再提交。

创建分镜时，脚本会记录每镜采用的资产和角色视角。通过助手创建时，可在加入画布前逐镜核对。展开镜头后，分镜图和视频节点都会带上该镜的资产引用，仍可在各节点的提示词或分栏修改。

在输入框旁点击「文档」，也可以把文件拖进输入区。每条消息最多加 2 个文档，单文件上限 8 MB。支持 TXT、Markdown、CSV、JSON、DOCX 和含文字层的 PDF。可以在发送前移除附件。助手在该轮读取正文，长文按本条指令选取相关段落，总计最多纳入 12,000 字符。完成后，对话历史保留附件名，适合需要保留和反复查阅的资料可收录到资产库。

## 语音输入

管理员在「控制台 → 模型与服务」接入「OpenAI 兼容语音转写」，填入接口地址和模型名，并设置「语音转写」的默认路由。重新打开创作助手后，输入框下方会出现「录音」和「音频」。

点「录音」后允许麦克风权限，点「停止录音」提交转写。录音满 60 秒会自动开始转写。浏览器需要 HTTPS 和麦克风权限。也可选择 WAV、WebM、OGG、M4A、MP4、MP3 或 FLAC 音频，最大 8 MB。音频会发给配置的转写服务，所得文字会添加到当前草稿供编辑。

勾选「实时预览」后，每录完约 5 秒就转写一个短片段，识别文字按录音顺序追加。节点和助手共用此设置，预览可能产生额外转写费用。停止录音时仍以完整录音的识别结果为准，取消录音会清除预览。

在画布按住说话键可边录音边点选素材，松开后转写并发送。已有草稿时，转写会追加到草稿供编辑。默认按键为 R，可在「按住说话」中选择空格、自定义一个字母或数字，或关闭。录音时按 Esc 可取消。

图片、视频和音频节点的提示词面板也提供「语音输入」和「音频转写」。点击开始和停止录音，或聚焦按钮后按住空格，松开后转写。也可以选择现有音频文件，适用于无法使用麦克风的页面。文字会追加到描述框。使用视频分栏时，文字会追加到刚编辑的栏位，默认使用「动作」。核对完提示词后可手动生成。

用快捷键录音时，单独说「停止」或「停止当前任务」会请求停止录音开始时所在对话的任务。排队的后续指令继续执行。点击「录音」所得的转写始终先放入草稿。

## 创作技能

在创作助手输入框下方打开「技能」。可以查看内置的产品镜头、分镜审阅、视频提示词和角色连续性技能，也可以新建个人技能，填写适用情境和创作步骤。

- **自动匹配**。开启后，助手根据本条消息和技能描述判断是否加载。对话会显示加载记录。
- **本轮使用**。点选技能后，它随下一条手动发送的消息生效。已发送的消息会显示所选技能，发送前也可以取消。
- **导入**。可选单份 Markdown，也可选根目录含 `SKILL.md` 的文件夹。文件开头的 `name`、`description` 会填入编辑表单，目录内的其他 Markdown 文件作为可按需读取的参考资料。保存前可以修改描述、指令和资料。

个人技能仅所属账号可查看和维护。它提供创作步骤，当前消息仍决定要执行的操作，助手沿用原来的工具权限和生成限额。

| `image_previs_frame` | 沿用导入分镜的固定白模构图与关联图片，在原分镜图节点追加正式画面 |
| `memory_search` / `memory_get` / `memory_use` / `memory_save` | 检索、读取、采用和保存资产库素材 |
| `creative_skill_load` | 加载本轮允许使用的创作技能和 Markdown 参考资料 |
| `video_remake_analyze` / `video_remake_status` | 分析原片镜头和人物，查看审核与导出进度 |
| `video_remake_split_long` | 按当前视频服务的时长上限拆分指定镜头，返回新镜头编号、原片时间范围和审核状态 |
| `video_remake_map` / `video_remake_locate` | 把原片人物关联到资产库角色，在镜头首帧建议人物位置 |
| `video_remake_preview` / `video_remake_generate` | 生成换角预览，使用已采用的首帧或入画帧生成镜头视频。用户也可指定已配置的 Seedance 服务和当前镜头的深度参考 |
| `video_remake_review` / `video_remake_export` | 采用指定版本或保留原镜头，按审核决定合成并保留原声 |
| `video_export_gif` | 把固定的视频版本或片段导出为循环 GIF，在对话中预览和下载 |
| `image_export_gif` | 从指定格数和范围的宫格图片导出循环 GIF |

「创作应用 → 循环动图」可从宫格图片、已有视频、参考图或文字开始。表情或像素动图可先用生图服务生成一张宫格，再按行合成为 GIF。需要连续摄影动作时，可先生成视频再导出。

在双帧对比窗口选择版本后，可直接交给助手审阅。两侧都有视频时检查动作衔接，选择分镜图时检查画面衔接。审阅结果卡支持「为当前镜头拟修改」，返回的方案经确认后才应用。审阅和拟修改都保留输入框草稿。

局部编辑接受当前会话已保存、且绑定同一节点和源图版本的选区。SAM 的透明选区会转换成重绘后端使用的灰度遮罩。选区可跨轮复用；换到不同源图版本时须重新选择，复用生成参数则继续使用原图与原遮罩。

下一镜展开后，可从卡片或分镜脚本点击「参考上一镜尾帧」。OneShot 截取上一镜当前视频版本的尾帧并连接到本镜分镜图，供生成时参考人物、道具位置和光线。切换上一镜版本后再次点击，可更新同一个引用编号。

分镜脚本和镜头清单会提示尾帧与当前版本的差异。有生成记录时，还会提示当前分镜图是否已经使用更新后的尾帧。

在分镜或镜头清单点击「对比衔接」，可并排查看上一镜的尾帧和本镜的首帧或分镜图，并在窗口内挑选版本。对比中的版本选择只对审阅窗口生效。

镜头清单可选择一段已生成的连续镜头，按分镜顺序送入剪辑。时间线使用送入时的画布视频版本。同一段镜头换用新版本时会打开对应的剪辑草稿。

换用分镜视频后，可在新剪辑顶部选择「沿用剪辑草稿」。选择同一段分镜的历史草稿，核对哪些片段将换用当前版本，再确认。原剪辑顺序、入出点、字幕、音乐和标题会带入新草稿。新视频过短时，对应片段继续使用历史素材，保持下游轨道的时间点。历史草稿可随时重新打开。

写分镜时先估算动作、停顿和对白需要的实际时间，再选择 5、8、10 或 14 秒的生成时长。单镜内容过长时拆成多镜，为每镜分别写首帧，并保持前后动作连续。「一句话成片」的 15、30 或 60 秒用于规划全片，分镜结果会显示实际计划的总时长。

分镜节点的「剪辑成片」和「一句话成片」会先检查是否缺少镜头视频。补齐后，两个入口与镜头清单的完整区间共用同一份草稿。已剪过的画幅、转场和字幕会保留。已有成片时，可继续剪辑原成片，也可按当前选中的镜头版本打开剪辑。

在镜头清单点击「排序」，可拖动镜头或用上下箭头移动。分镜图、视频和历史版本随原镜头保留，新的顺序用于批量生成和剪辑。固定尾帧仍指向原视频版本，受影响的镜头会显示衔接提醒。排序可通过画布撤销和重做。

在镜头清单可直接连接或改用上一镜当前版本的尾帧。移除尾帧引用会同时清理分镜图提示词里的对应引用标记，原取帧图片和生成历史可继续使用，操作支持撤销。

镜头清单中的「编辑」可修改首帧描述、场景、时长、景别、运镜、动作、台词和声音。保存会把相关改动同步到原分镜图和视频节点中仍沿用分镜设定的字段。节点上的独立设置和成品版本会保留。保存后可打开当前镜头的重生成计划。

「新增镜头」可指定插入位置。「复制设定」会以原镜头的文字和人物设定填写新镜头，独立展开后可生成自己的分镜图和视频。「移出分镜」保留画布上的原节点、连线和历史版本，可撤销恢复镜头。

镜头清单中的「关联素材」可直接选用画布上已有的分镜图或视频节点，剪辑时使用节点当前选择的视频版本。也可只关联其中一种，批量展开时会补齐缺少的节点。用现有分镜图新建视频节点时，两者会建立首帧连线。已有视频的原始输入关系会保留。

生成脚本时，超过 14 秒的镜头会单独拆分。系统会核对拆分后的镜头数和总时长、动作与对白顺序、说话人，以及各镜的独立首帧说明。其他镜头沿用初稿。

可以对创作助手说「把这段剧情拆成一份竖屏分镜脚本」。助手与画布上的分镜功能共用镜长校验。对话卡会列出每镜时长、首帧、动作和台词，确认「加入画布」后可继续编辑。明确引用的画布图片会绑定到拟定时使用的版本。

从镜头清单新建剪辑时，会按分镜的目标镜长取用视频。素材较短时先取可用部分，片段面板会显示缺多少秒，并可更换版本或预览减速。再次打开已保存的草稿时会保留手动剪辑点和速度。

剪辑台顶部的「核对镜长」会集中列出各段的计划时长、当前时长和素材缺口，点击「定位」可跳到对应片段。素材够长时可以勾选调整出点，沿用当前入点和速度。与原声同步的重制片段保留现有剪辑点。

素材偏短时，清单会显示从当前入点开始、按原速仍够长的备选版本数。「预览备选」优先打开符合镜长的画布当前版本，否则打开最近一个符合条件的版本。确认应用后，剪辑才会换用该素材。

已有分镜关联且素材短于计划、没有够长的备选时，可打开「补拍计划」。计划会定位到对应的画布视频节点，列出按当前入点和速度需要的素材长度，以及当前配置的时长是否偏短。提交生成仍需在计划中确认。

当前视频节点的时长偏短时，补拍计划会提供能覆盖所需长度的最小时长档位，可直接应用到该视频节点。所需时长超过所有可选档位时，计划会显示最长档位。

补拍结束后，任务进度里的「返回剪辑核对」会打开原草稿，并定位到对应的片段。够长的补拍结果可直接预览，确认应用才会替换片段。结果偏短或生成失败时仍可返回原草稿查看。

分镜展开后，可在脚本或助手卡片打开单镜生成计划。可先生成分镜图、使用选定分镜图生成视频，或确认按依赖顺序补齐两步。计划使用该镜自己的画布节点，生成结果留在各自的版本栏。

镜头清单的「批量生成」可指定起止镜头。范围内未展开的镜头可以先展开，再查看参考素材、任务数量和尾帧提醒。你可以选择补齐未生成节点、只生成分镜图或只生成视频。

运行计划默认沿用已固定的尾帧。勾选「生成分镜图前刷新已有的上一镜尾帧」后，分镜图会等待上一镜的视频结果再取尾帧。如果上一镜的视频不在本次计划内，就用确认计划时选中的版本。尾帧仍使用原引用编号。上一镜生成失败或选定的版本发生变化时，依赖该尾帧的分镜图会跳过。

从头生成连续镜头时，可单独勾选「为未连接的分镜图连接上一镜尾帧」。确认页会显示将新增的引用，生成时自动把尾帧和对应的参考提示词加到分镜图。第一镜无需尾帧。只生成分镜图时，连接需要上一镜已有可用视频。

也可以对创作助手说「补齐第 3 到 6 镜，让每张分镜图都参考上一镜最新的尾帧」。助手会在卡片上列出生成范围和尾帧选项。打开卡片后可以调整范围和选项，确认才开始生成。

## 第二阶段交互

创作助手的活跃对话会在本轮引用节点和已提交生成的目标节点旁显示状态。点击「待确认」或「执行中」等标签，可回到对应对话。切换对话时保留各自的输入草稿。

右键节点或多选后选择「发起新对话」，可把本次选中的节点和版本带入独立对话。也可右键历史版本的 Tab，直接从该版发起新对话。

发送前可选择「本轮范围」。「仅分析」允许读素材和讨论。「仅拟方案」可准备待确认的模板、分镜和生成计划。「头脑风暴」适合比较故事、镜头和风格的不同方向，卡片会列出执行方法、取舍和第一步。点击「继续讨论这个方向」或「拟制作方案」会把选中的方向带入输入框，并预选对应范围。核对后再发送，排队消息沿用发送时的范围。

- **从画布交给助手**。选择节点后点击工具栏的「交给创作助手」，即可在对话中引用该节点。在图片编辑器圈好区域后点击「把圈选区域加入助手对话」。输入框上方会显示可预览、可移除的选区。发送消息时，局部编辑使用圈画时的图片版本。
- **引用审阅评论**。在画布评论中点「带到助手」，可以把评论、近期回复和评论时的素材版本带进对话。确认好修改要求后点发送。审阅内容也可以从对话历史里的「引用审阅评论」展开查看。
- **只改背景 / 主体**：`image_edit` 的 `target=background/foreground` 会调用真实分割工具，生成选区预览再提交遮罩重绘。背景编辑保护整个识别出的主体及一像素边缘，最终合成保持遮罩外 RGBA 像素一致。自动分割是建议，复杂场景可改用手动区域。
- **手动选区**：助手调用 `image_select(mode=manual)` 后进入等待输入状态。聊天面板显示「打开选区编辑器」，用户画好区域后点击「发送选区给助手」，任务才继续。关闭窗口、刷新或重启 Web 服务不会把等待选区变成整图生成。停止本轮后，旧选区请求不再执行。
- **图层**：重绘结果按编辑前底图和生成区域拆分，避免叠加在已经改过的结果上。透明度、顺序、位置、尺寸、隐藏和素材导入在原节点追加可编辑版本，图层结构写入版本记录。手动编辑器合并保存时也保留结构。
- **对比与参数**：结果卡片提供「对比」「编辑图层」「复用参数」。复用参数按钮将原图、遮罩和设置载入编辑器；实际重新生成由用户点击或通过对话调用 `image_reuse`。原始版本保留。
- **Markdown**：聊天消息支持标题、粗体、列表、表格、引用、链接、图片和代码块；代码块提供复制。随站点部署 Marked 18.2.1 与 DOMPurify 3.4.18，包完整性和许可保存在 `static/vendor/`，无外部 CDN 依赖。参考 [Marked 文档](https://marked.js.org/) 与 [DOMPurify 文档](https://github.com/cure53/DOMPurify)，渲染前清理不允许的 HTML、事件与链接协议。

### 视频重生成修复

2026-11-17 的聊天记录显示：助手曾两次用 `image_generate` 执行视频请求，并将静态图片解释成视频服务异常；对应时间没有视频任务入队。现已增加独立视频工具，提示模型按结果媒体类型作答，并在保存前探测真实视频流与时长。

`video_regenerate` 复用视频节点的提示词、时长、画幅、关键帧 / 人物设定和配置，可用 `replacements` 指定修正后的图片节点。重生成的结果保存在原视频节点，历史视频不覆盖。每个新版本记录输入连线（含首尾帧、关键帧时间与人物设定）和节点参数，切换Tab同步恢复；旧版本在首次修改前补存当前输入快照。已删除的输入节点不会重建。任务进行时锁定版本切换，失败时恢复未被用户改动的旧输入与参数。本轮撤销恢复版本、节点和连线，后续手动改动会触发冲突保护。`media_describe` 对视频抽取实际画面，避免把关键帧分析冒充对视频本身的检查。

新视频提交成功即创建画布节点、首尾帧 / 关键帧 / 人物设定连线和进度，不再等到生成完成；重生成则直接在原节点显示进度并更新对应输入连线。浏览器只跟踪状态，服务端在同一个节点保存完成结果，避免重复节点或重复版本；收起聊天仍同步画布。失败或取消会清除进度并显示错误，用户删除等待中的节点后不会重新创建。相关撤销同时处理本轮建立的节点和连线。

视频生成与重生成使用已有视频服务和任务队列。

### 用对话重制现有视频

1. 把原片拖入画布，选中视频，对助手说「为替换角色分析这段视频的人物和镜头」。分析保存在当前原片版本。也可以从视频右键菜单打开「视频重制 · 替换角色」。遇到分析缺失时，可以请助手「补充缺失的镜头分析」，也可以在工作区点击「重试视觉分析」。已确认的剪辑点和审核决定会保留。
2. 在对话里用 `@` 选中资产库角色，指定要替换的原片人物和镜头范围。例如「把第 1、3 镜里穿红衣的人换成 @林森，先帮我定位」。从聊天结果打开重制工作区，检查建议位置并确认选区。人物晚入画时，在实际入画帧选区。
3. 请求生成预览，在工作区采用预览后，再请求生成对应的镜头视频。通过结果卡片打开镜头，用原声对照播放。需要保留原片背景和前景遮挡时，可以在工作区调整校正帧和保护区，再做局部合成。
4. 在聊天卡片里选择视频版本或保留原镜头。处理完待审核的镜头后，对助手说「合成并保留原声」。完成后可以直接从聊天下载，也可以在重制工作区预览或放入画布。成片文件不可用时，可以用同一组审核结果重新合成。

跨镜头的请求会先显示「确认换角计划」。勾选镜头后，已确认选区的镜头会提交换角预览，需要补选区的镜头可从卡片跳到重制工作区。也可以在卡片中采用已完成的预览，再生成镜头视频。

刷新对话后，计划卡会读取已确认的镜头和对应任务。未确认的勾选保存在当前浏览器。提交中断时卡片会显示已知任务，供核对后继续。

画布顶部的「镜头」可在原片与分镜脚本之间切换，查看镜头状态、定位版本并送入剪辑。重制工作区也有「送入剪辑」入口。剪辑台按原剪辑点放入采用的镜头，保留其余段落和原声。之后在重制工作区采用另一版本，再回到剪辑台点击对应段的「更新这一镜」。

剪辑台在当前浏览器按账号和项目保存草稿及播放位置，可从「镜头 → 恢复剪辑」继续。导出前会检查素材、剪辑点、对应审核版本和画幅。失败后可回到同一草稿修正，再提交导出。

同一镜头替换多人时，先为第一位人物完成局部合成并点击「加入角色图层」。切换人物映射，分别制作其他人物的图层。图层列表从下往上合成，可调整重叠时的覆盖顺序。点击「合成所选角色」，预览并采用结果。

### 验收视频重制

服务已运行时，可以用一段带原声的短视频、角色参考图和首帧人物框，在私有验收画布跑完真实模型流程。脚本使用配置中的视觉、生图和视频服务，保留验收画布和素材供复查，模型调用可能产生费用。

```bash
python scripts/smoke_video_remake.py --url https://oneshot.example +  --username smoke --source source.mp4 --reference character.png +  --shot 1 --rect 0.25 0.15 0.70 0.92 --output remake-result
```

按实际人物位置调整 `--rect` 的四个归一化坐标。输出包含换角预览、局部合成、最终成片和验收报告。报告记录生成任务、原片与成片时长和原声音轨匹配度。角色身份、姿势和遮挡效果可用生成文件目视验收。

真实素材验收应覆盖双人交叉遮挡、人物进出画、手机竖拍和需要拆分的长镜头。逐镜对照人物脸部和服装、出入画时间、遮挡边界及抖动，再检查导出方向、片段顺序和原声。双人用例需分别审核角色图层后再检查合成。

## 执行与恢复

- 会话、模型消息、步骤和工具结果存入 SQLite。会话按账号与画布隔离，操作沿用当前账号权限；账号停用或画布权限撤回后不能继续修改。
- 每轮固定源图片版本，用户之后切换当前版本不会改变正在执行的输入。
- 每轮最多生成 4 张图、1 段正式视频、1 段音频、渲染 1 段白模预演并调用 16 次工具，执行时间上限 30 分钟。限制由服务端执行。
- 多段视频可分成多条消息发送。当前指令还在执行时，下一条消息会进入队列。
- 指定「本地续拍」时，助手使用原片末帧作为新片的首帧，补拍片头时用原片首帧作为新片尾帧。自动续拍在没有连续画面服务时也会采用这条路径。接点帧与新片段会连回原片，支持附加图片参考。本地 H3 成片时长按引擎帧数取整，约为 5.2 至 14.4 秒，更短的镜头可剪辑取用。
- 关闭面板或刷新页面后，服务端任务继续。重新打开后加载会话与进度。
- 浏览器对发送状态不明的消息保留请求编号，重试使用相同编号，避免重复提交。
- 工具效果与幂等标记一起写入画布；已返回任务编号的生成可在 Web 服务重启后恢复跟踪。若服务恰好在提交过程中中断而未记录编号，会标记待核实，并停止本轮追加生成。
- 第三方正在执行的生成沿用平台已有的恢复限制，不能保证重启后继续跟踪；不会自动重新付费提交。
- 支持流式回复的模型会边生成边显示文字，刷新或重新打开对话时会恢复正在生成的回复。完成后按 Markdown 显示，工具在完整收到参数后再执行。不支持流式回复的接口会按完整消息显示。

“停止”阻止后续操作并尝试取消本轮未完成生成，已完成结果保留。“撤销本轮”恢复该轮的画布变化，不撤销已经发生的计算或费用；相关节点后来被手动修改、连线或编组时，拒绝覆盖后续操作。

画布保存保留现有版本检查，并对不重叠的手动改动和助手改动进行三方合并。同一内容发生冲突时，本地完整版本暂存在浏览器中，用户可保存为独立画布副本；服务端版本保留。服务端工具也会检查准备修改的字段是否在本轮中被用户更新。

## 实现与接口

`agent_chat.py` 提供模型工具循环、白名单注册、参数校验、业务适配、持久化和生命周期管理。`static/agent-chat.js` / `.css` 提供聊天面板、事件展示、引用和画布同步。

| 接口 | 用途 |
| --- | --- |
| `GET /api/chat/sessions?board=…` | 当前账号的画布会话 |
| `POST /api/chat/sessions` | 创建画布会话 |
| `GET /api/chat/sessions/{id}?after=…` | 增量事件和执行状态 |
| `POST /api/chat/sessions/{id}/messages` | 发送消息，携带唯一请求编号和选择 |
| `POST /api/chat/runs/{id}/stop` | 停止本轮 |
| `POST /api/chat/runs/{id}/undo` | 撤销本轮画布变更 |
| `POST /api/chat/runs/{id}/selection` | 为等待中的请求提交真实 PNG 遮罩 |

模型适配沿用平台的 Chat Completions 兼容服务，核对了 [OpenAI 官方 Function calling 文档](https://developers.openai.com/api/docs/guides/function-calling?strict-mode=disabled)。所选模型需要正确支持函数工具调用；不支持时可能返回接口错误，或只能进行文字问答。第一阶段已使用当前配置的 DeepSeek 完成真实工具调用验证。
