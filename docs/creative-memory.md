# 创作记忆

素材库支持角色、场景、道具、风格和背景资料。上传图片/视频、画布生成结果与纯文本资料可以归入同一条记忆；生成任务会保存采用的记忆、参考图版本和提示词，形成可查的生成历史。

## 使用

- 点击顶部「资产库」或左侧资产图标，进入独立资产库。左侧分类，中间卡片列表，右侧详情；支持按名称、别名、标签、设定搜索，以及范围、来源和更新时间筛选。
- 资产库 → 新建资产，填写名称、别名、标签、设定和使用约束。默认保存在当前项目，也可选择个人素材库跨项目使用。
- 可直接「上传素材」，或「从画布收录」已有图片、视频与文本；也可在详情中上传文件或“采用当前选中素材”，保存后成为参考素材。点击参考图片可指定默认参考图。视频保留为资料，不会被冒充图片传给生成模型。
- 在创作助手或图片/视频提示词中输入 `@`：菜单列出当前项目和个人库中的可用记忆，继续输入可按名称、别名、标签筛选。↑/↓ 选择，Enter/Tab 补全，Esc 关闭，也可鼠标选择。中文输入法选词时不拦截 Enter。
- `@林森` 自动采用该人物的默认参考图、设定和约束。相同名称/别名对应多个记忆时，选择器插入唯一 ID 引用，手写有歧义的名字会提示澄清。
- 未写 `@` 时，助手可以检索记忆、读取详情，再决定采用哪些素材；`memory_use` 只作用于当前轮后续生成。
- 点击卡片查看原图、播放视频、编辑设定与参考版本。「放入画布」创建对应媒体或文本节点，「@ 引用」将资产带入助手输入框。其他用户的共享资产以只读方式展示；「素材历史」保留原有快速浏览入口。
- 资产详情的“生成历史”可将结果加入参考素材。新增素材与生成结果都不会自动替换已批准的默认参考图。
- 无参考图的背景资料以文本加入生成上下文，也可放入画布成为文本节点。

## 生成接口与工具

`GET/POST /api/memory`、`GET/DELETE /api/memory/{id}` 管理记忆；`/api/library` 保留兼容接口。检索支持 `board`、`q`、`kind` 参数。原有 `library.json` 按原 ID 惰性迁移，原文件保留，删除标记防止旧记录再次导入。

生成接口接受 `memory_ids`，并解析提示词和结构化视频字段中的 `@名称`。服务器从有权限的记忆读取实际参考图；客户端传入的 `memory_used` 不被信任。返回的 `memory_used` 与 `memory_context` 用于版本追溯与重生成。

助手工具：

| 工具 | 作用 |
| --- | --- |
| `memory_search` | 按名称、别名、标签、设定检索 |
| `memory_get` | 读取设定、参考素材和当前账号生成历史 |
| `memory_use` | 为本轮后续生成采用指定记忆 |
| `memory_save` | 保存用户要求记住的设定、已生成或上传素材 |

图片以真实参考图输入模型。视频使用人物/场景参考槽，保留原有首帧、尾帧、关键帧和时间；不会将人物设定图当成首帧。H3 图像编辑同样支持记忆；原生 SD 遮罩重绘不支持额外参考图，会提示切换 H3。单次最多采用 8 条记忆、总计 9 张参考图片，超出会明确报错。

## 存储与访问

SQLite 表 `creative_memories` 保存设定与已批准参考，`memory_uploads` 保存上传归属，`memory_jobs` 和 `memory_outputs` 保存任务引用与生成来源。重复轮询任务不会重复写入生成历史。账号间私有记忆隔离，生成历史只展示当前账号自己的结果。共享素材可读取，修改和删除需要所属账号或管理员权限；项目素材按可访问画布过滤。更新支持 `mtime` 冲突检查。

当前检索采用名称、别名、标签与正文匹配，助手通过语言模型判断相关性；不包含向量检索、自动人脸身份识别或视频片段语义检索。画布撤销只撤销画布操作，已写入记忆及生成文件继续保留。

## 验证

后端 HTTP 测试在 4090 隔离数据库与媒体目录运行；本地仅运行无需服务器的 DOM 测试。测试涵盖上传、版本保护、账号/项目隔离、歧义引用、实际生成请求注入、首尾帧保留、生成历史去重、旧库迁移、助手检索采用与保存重试，以及输入菜单的键盘/鼠标补全。资产库 DOM 测试覆盖分类、搜索、来源/范围筛选、上传保存删除、视频预览、共享只读、画布收录/放置、助手引用及失败重试。
