# 创作记忆

素材库支持角色、场景、道具、风格和背景资料。上传图片/视频、画布生成结果与纯文本资料可以归入同一条记忆；生成任务会保存采用的记忆、参考图版本和提示词，形成可查的生成历史。

## 使用

在角色资产详情打开「参考图更新影响」，可以按项目查看有权限的画布中使用了旧参考图的版本和重制镜头。画布版本会标出受影响的视角，以及需要重新定稿的视角。对于有权使用该角色且已有选区的重制镜头，可以跨项目勾选并用新参考图生成预览。生成后到对应项目的重制工作区审核，原有版本可继续使用。

- 点击顶部「资产库」或左侧资产图标，直接打开当前资产库。同一项目的画布共用项目资产库，独立画布各自使用画布资产库。个人、共享和团队资产从范围菜单分别进入。
- 新建、上传、从画布收录和助手保存资产默认归入当前项目或独立画布。旧个人资产仍保存在个人库，可以打开详情用「保存到」改归属。画布移入项目后，该画布原有资产也可在项目其他画布使用。画布移出时，绑定到它的资产随画布走，直接保存到项目的资产仍由该项目共享。
- 项目素材仅项目创建者可以读取和修改。移动画布时，项目素材留在原项目。解散项目时，项目素材移到创建者的个人素材库。
- 在资产库新建自定义文件夹，点「归档资产」即可多选并移动。个人文件夹按账号保存。筛选具名团队时，团队成员查看同一套文件夹，团队管理员管理文件夹和归档，成员可归档自己收录的素材。删除文件夹后，其中的资产回到未归档。
- 在资产的「范围」选择所属团队，或在从画布批量收录时选择团队。团队成员可以筛选、预览、下载、复制或通过 `@` 引用素材。素材所有者管理原资产；移除团队成员后，团队库访问随之撤销。
- 在画布打开一张折叠分组卡，点击「收录到资产库」，选择资产范围和目标文件夹后确认。当前图片、视频和音频版本分别存为资产，文字存为可检索的文档。一批最多收录 100 项，确认后直接打开目标文件夹。
- 「上传素材」也可导入 TXT、Markdown、CSV、JSON、DOCX 和含文字层的 PDF。保存前可以展开检查正文。资产搜索会查找已导入的正文，生成时输入 `@资产名称` 会按当前提示选取相关摘录。单文件上限 8 MB，正文保留最多 6 万字。扫描件需先转成可复制文字。
- 可直接「上传素材」，或「从画布收录」已有图片、视频与文本；也可在详情中上传文件或“采用当前选中素材”，保存后成为参考素材。点击参考图片可指定默认参考图。视频保留为资料，不会被冒充图片传给生成模型。
- 在创作助手或图片/视频提示词中输入 `@`。菜单列出当前项目、当前画布、个人库和共享范围里的可用记忆，可按名称、别名、标签筛选。↑/↓ 选择，Enter/Tab 补全，Esc 关闭，也可鼠标选择。中文输入法选词时不拦截 Enter。
- 图片和视频生成提示词也可以用 `@` 搜索画布上的图片。选择后会建立输入连线，并在参考图栏显示锁定的版本。视频的自由描述和分栏填写都支持引用。切换源节点的 Tab 不会改变这条连线，想更换时可在参考图栏点击「改用当前版本」。
- 视频提示词的 `@` 菜单也支持画布视频和音频。可以选用指定版本，再在参考栏调整视频入点和出点。生成使用已配置、支持相应参考类型的服务。
- 在创作助手、图片和视频提示词或音频「参考生成」中，输入 `@节点名#` 浏览该节点可用的历史版本，或输入 `@节点名#2` 直接查找第 2 版。选择后会锁定该版本，来源节点继续显示当前版本。
- `@林森` 自动采用该人物的默认参考图、设定和约束。相同名称/别名对应多个记忆时，选择器插入唯一 ID 引用，手写有歧义的名字会提示澄清。
- 在图片或视频提示词、分栏以及创作助手中输入 `@林森#`，可从菜单选择已定稿的视角。继续输入「头肩」或「背面」可缩小范围。可以为同一角色选择多张，选中的视角用于本次生成。
- 未写 `@` 时，助手可以检索记忆、读取详情，再决定采用哪些素材；`memory_use` 只作用于当前轮后续生成。
- 点击卡片查看原图、播放视频、编辑设定与参考版本。「放入画布」创建对应媒体或文本节点，「@ 引用」将资产带入助手输入框。其他用户的共享资产以只读方式展示；「素材历史」保留原有快速浏览入口。
- 资产详情的“生成历史”可将结果加入参考素材。新增素材与生成结果都不会自动替换已批准的默认参考图。
- 无参考图的背景资料以文本加入生成上下文，也可放入画布成为文本节点。

## 生成接口与工具

`GET/POST /api/memory`、`GET/DELETE /api/memory/{id}` 管理记忆；`/api/library` 保留兼容接口。检索支持 `board`、`q`、`kind` 参数。原有 `library.json` 按原 ID 惰性迁移，原文件保留，删除标记防止旧记录再次导入。

生成接口接受 `memory_ids`，并解析提示词和结构化视频字段中的 `@名称`。服务器从有权限的记忆读取实际参考图；客户端传入的 `memory_used` 不被信任。返回的 `memory_used` 与 `memory_context` 用于版本追溯与重生成。

助手工具：

| 工具 | 作用 |
| --- | --- |
| `memory_search` | 按名称、别名或镜头描述检索可用角色、场景、道具、风格与背景资料 |
| `memory_get` | 读取设定、参考素材和当前账号生成历史 |
| `memory_use` | 为本轮后续生成采用指定记忆 |
| `memory_save` | 保存用户要求记住的设定、已生成或上传素材 |

图片以真实参考图输入模型。视频使用人物/场景参考槽，保留原有首帧、尾帧、关键帧和时间；不会将人物设定图当成首帧。H3 图像编辑同样支持记忆；原生 SD 遮罩重绘不支持额外参考图，会提示切换 H3。单次最多采用 8 条记忆、总计 9 张参考图片，超出会明确报错。

可让助手为一镜选用角色的已定稿视角。比如在极近景只用正面头肩，拍背影时采用主图和背面图。助手的图片和视频生成工具可以用 `memory_views` 为每个角色指定最多三张对应视角。普通 `@角色` 采用默认参考图。全屏预览的「版本信息」会显示生成时用到的资产，并可打开该版本实际采用的参考图。

重新生成视频时，画布和助手会沿用所选版本的角色、场景和背景资料，并读取这些视角目前的定稿图。画布的参考栏可以逐个取消沿用。提示词中的显式 `@` 引用仍然有效，如要完全移除该素材，请同时删除对应引用。

要沿用自己生成的视频当时用的参考图，可以选中该视频版本，对助手说「用这个版本生成时的原参考图重新生成」。助手从该账号的生成记录取图，并检查旧图仍可访问且仍收录在原资产中。结果在原视频节点追加版本。

## 存储与访问

SQLite 表 `creative_memories` 保存设定与已批准参考，`memory_uploads` 保存上传归属，`memory_jobs` 和 `memory_outputs` 保存任务引用与生成来源。重复轮询任务不会重复写入生成历史。账号间私有记忆隔离，生成历史只展示当前账号自己的结果。共享素材可读取，修改和删除需要所属账号或管理员权限；项目素材按可访问画布过滤。更新支持 `mtime` 冲突检查。

助手搜索优先使用当前画布或项目的资产，也可明确搜索所有有权使用的资产。资产库里输入镜头描述后点「按描述找」，会在当前选中的范围和分类内按相关性显示结果。直接命中名称时按名称返回，描述性查询会用配置的文本模型判断候选的相关性。模型暂不可用时回退到关键词检索。画布撤销只撤销画布操作，已写入记忆及生成文件继续保留。

## 验证

后端 HTTP 测试在 4090 隔离数据库与媒体目录运行；本地仅运行无需服务器的 DOM 测试。测试涵盖上传、版本保护、账号/项目隔离、歧义引用、实际生成请求注入、首尾帧保留、生成历史去重、旧库迁移、助手检索采用与保存重试，以及输入菜单的键盘/鼠标补全。资产库 DOM 测试覆盖分类、搜索、来源/范围筛选、上传保存删除、视频预览、共享只读、画布收录/放置、助手引用及失败重试。
