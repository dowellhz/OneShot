# 图像编辑

在画布选中一张已上传或生成的图片，点击工具栏的「编辑图片」，也可从右键菜单打开。

编辑器以浮动窗口打开：拖动标题栏移动窗口，拖动右下角调整大小，双击标题栏或点「最大化」切换最大化 / 还原。点击「收起」只保留标题和任务进度，点「展开」继续编辑。窗口外可继续操作画布，位置和尺寸会在当前浏览器中记住；关闭窗口不会取消已提交的任务。

- **局部重绘**：用画笔或矩形选区标记要修改的位置；可擦除、撤销选区、清空或反选。输入修改要求后生成，粉色区域为编辑范围。
- **整图编辑**：通过文字修改整张图的风格、光线、服装或场景。
- **智能扩图**：设置左、右、上、下边距（每侧 0–2048 像素），生成延伸场景，保留原图区域。
- **裁剪 / 调色**：在图片上拖出裁剪矩形，调整亮度、对比度、饱和度后保存；旋转与翻转按钮直接保存新版本。不依赖 AI 模型。

按住「对比原图」查看打开编辑器时的图片。每次保存或生成都会追加图片节点的历史版本；点击节点右侧版本Tab或编辑器底部缩略图切换，可继续编辑任意旧版本。助手对图片的修改也使用同一节点的历史版本。原始文件不会被覆盖。

AI 任务使用平台默认图像服务，也可在编辑器内单独选择已配置服务。服务须支持参考图编辑。任务与现有画布共用队列、取消和任务中心；提交成功后可关闭编辑器，完成后自动保存新版本。浏览器刷新后任务仍由节点继续跟踪。

## 生成与合成

交互参考 [Krita AI Diffusion](https://github.com/Acly/krita-ai-diffusion) 的选区、上下文和历史流程，代码为独立实现。参考其 [resolution.py](https://github.com/Acly/krita-ai-diffusion/blob/main/ai_diffusion/backend/resolution.py) 对选区周围上下文的处理，以及 [workflow.py](https://github.com/Acly/krita-ai-diffusion/blob/main/ai_diffusion/backend/workflow.py) 的遮罩合成设计。

局部编辑会裁出选区及周围内容，将原图和一张粉色选区示意图提供给现有改图模型。模型结果按输入上下文尺寸对齐，再通过遮罩合回原图。羽化只影响选区内部，遮罩以外的 RGBA 像素保持一致；扩图只写入新增区域。

参考图编辑模式使用「改图模型 + 遮罩合成」，另提供下文介绍的原生遮罩重绘。没有接入 Krita 插件、ControlNet、LoRA 或实时绘画后端。模型对选区内容的理解和透视对齐仍取决于服务能力；合成能保护选区外像素，但不保证生成区域一定符合提示词。融合比例表示生成结果的混合不透明度，并非扩散去噪强度。调色预览使用浏览器滤镜，保存使用 Pillow，不同实现可能有轻微色差。

图片支持 PNG / JPG / WEBP，按 EXIF 方向读取，最大边长 8192 像素、总像素 3200 万。编辑结果保存为 PNG，保留透明通道。

## 接口与验证

- `POST /api/image-edit/transform`：`ref`、可选 `crop: {x,y,w,h}`、`rotate`（90 度的倍数）、`flip_x` / `flip_y`、`brightness` / `contrast` / `saturation`（0–2，默认 1）。
- `POST /api/image-edit/generate`：`ref`、`mode`（`region` / `whole` / `outpaint`）、`prompt`，可选 `provider`、`strength`（0.01–1）、`feather`（0–128 像素）、`padding`、`seed`、`board`、`label`。局部模式还须提供同尺寸 `mask` 文件引用，白色为编辑区域、黑色为保护区域。

生成接口返回现有任务 ID，继续使用 `/api/jobs` 和 `/api/cancel`。合成参数保存在 `data/image-edits/`；本地引擎和 ComfyUI 任务在服务重启后恢复时会重新加载这些参数。第三方正在执行的任务沿用平台既有的恢复限制。中间图片与结果使用平台既有媒体目录。

```bash
python -m unittest discover -s tests -v
node --check static/image-editor.js
```

测试使用合成图片和模拟模型服务，覆盖选区外像素保护、融合比例、扩图、透明度、裁剪旋转、输入验证、取消，以及三条生成链路。真实模型效果需在已配置模型 / API Key 的部署环境验证。

2026-11-17 在 4090 的现有 H3-Image 服务完成真实局部改色验证：将合成小屋图片的红屋顶改为蓝色，模型生成耗时 49.6 秒（不含首次加载）。最终图片为 512×384，选区内 13,356 个像素发生变化，选区外 183,252 个 RGBA 像素全部与原图一致。该验证覆盖真实模型输入、生成、遮罩合成及结果目视检查；浏览器交互验证尚未完成。

## 完整编辑工作区

- **缩放与平移**：在图片上滚轮缩放，按空格或鼠标中键拖动平移；工具栏提供 100% 和适应窗口。画笔选区始终使用原图坐标。
- **草稿恢复**：按账号、画布、图片节点和源图分别保存。选区笔画、重做记录、提示词、图层、位置、参数和视图会自动保存；重新打开或刷新后恢复。断网时优先保留当前浏览器副本，草稿状态在历史栏上方显示。
- **选区编辑**：支持撤销、重做、清空、反选、圆形笔刷光标；B 画笔、E 擦除、R 矩形、W 智能选物、[ / ] 调整画笔大小，⌘/Ctrl Z 撤销、⇧⌘Z / Ctrl Y 重做。
- **结果对比**：支持按住查看原图、滑杆对比和并排对比；前后尺寸不同时使用并排展示。
- **参数复用与重试**：新生成版本记录源图、遮罩、模型选择、强度、羽化、扩图边距、步数和种子（本地模型记录实际种子，第三方以其返回参数为准）。历史栏「复用参数」恢复设置，「重新生成」可重试上次提交。
- **图层**：支持导入、显示 / 隐藏、上下排序、不透明度、位置与尺寸调整、拖动移动、选区转透明图层、提取生成区域和合并保存。每次合并生成新 PNG 版本，原始文件保留。
- **智能选物**：SAM2 根据点击生成选区；Shift 点击排除区域，可结合画笔修正。
- **智能抠图**：SAM2 自动前景分割去除背景并添加透明图层；也可将手动或智能选区直接转为透明图层。
- **原生遮罩重绘**：选择「原生遮罩重绘（SD）」后，将图像与遮罩直接送入专用 inpainting 模型，另提供重绘强度和采样步数。它与 H3 共用 GPU 队列，切换时释放前一个大模型，选区外仍有最终合成保护。中文要求会通过已配置文本服务翻译；没有文本服务时可直接填写英文。
- **阶段进度**：区分加载、提示词与参考图处理、生成、解码、选区合成，并显示耗时与排队位置。
- **窗口布局**：支持靠左 / 靠右停放，拖至屏幕边缘可吸附；记住窗口大小、位置、停靠与最大化状态。

在画布空白处右键，选择「整理对齐…」，也可在节点右键菜单选择「整理图片与视频…」。整理范围可切换「选中的图片与视频」和「全部图片与视频」；默认提供「按关系整理（图片左 · 视频右）」：把有连线关系的素材作为一组，图片在左列按首帧 / 关键帧 / 尾帧排序，视频在右列对应排列，同一组图片生成的多个视频上下排开。也可选择网格整理、六种对齐和水平 / 垂直等距排列。网格、对齐和等距排列均按节点实际尺寸留出间距，并避开范围外未移动的节点。左 / 右 / 水平居中对齐会纵向排开，顶部 / 底部 / 垂直居中对齐会横向排开；空间不足时等距排列会扩展范围，避免负间距重叠。节点间留出至少180像素水平间距或140像素垂直间距，容纳标题栏、版本Tab与连线接口。操作只改位置，保留连线、版本、图层、生成参数和正在执行的任务，支持 ⌘/Ctrl Z 撤销和重做。至少两项可整理，至少三项可等距排列。

画布多选后显示整理工具栏，支持六种对齐、水平 / 垂直等距排列、编组、取消编组和 ZIP 批量下载。至少三个节点可等距排列，拖动分组标题可整体移动；⌘/Ctrl G 编组，⇧⌘/Ctrl G 取消编组，编组和位置调整支持画布撤销 / 重做。

### 调整图片布光

右键图片选择「调整图片布光」，或在图像编辑窗口切换到「布光」。在图片上拖动光源，也可以用滑块调整光源位置、主光强度、曝光、冷暖和轮廓光。支持按住「对比原图」或使用滑杆对比。

「保存布光为新版本」按原图尺寸保存 PNG，并保留透明通道。手动预览根据画面亮度和边缘估计光影。如果需要重建阴影，点「交给模型重打光」，在整图编辑中确认布光提示词和图像服务后生成。

### 图片换机位

右键图片选择「图片换机位」，在机位示意图上拖动相机，或使用侧面、背面、高机位等预设。也可以单独调整环绕、俯仰、拍摄距离、景别和焦段。补充要求可留空，一次可生成 1–4 张候选图，结果留在原节点的版本栏。

机位图用来设定构图。原图中看不到的区域由模型推演。打开历史版本的「复用参数」可恢复原图和机位设置，制作复盘会记录这些参数。

### 调整像素尺寸

右键图片选择「调整像素尺寸」，或者在「裁剪 / 调色」里展开「像素尺寸」。输入目标宽度和高度，可锁定比例。解锁后可以用透明补边保留完整画面，也可以选择居中裁切或拉伸。尺寸预览会考虑当前裁剪选区和调色设置。

点「保存指定尺寸」会在同一节点追加 PNG 版本。创作助手也能调整像素尺寸，默认使用透明补边。

### 视频合并为 Tab 与拆开

将一个已生成的视频拖到另一个视频上，输入连线一致时会显示「松开合并为 Tab」。松开后保留一个画布节点与全部历史版本；也可多选视频后右键选择「合并为 Tab」。同一组图片 / 文字节点、首尾帧角色和关键帧时间相同才可合并，生成参数和种子可不同。正在生成的视频和成片节点不能合并。

右键版本 Tab 可「拆出这个 Tab」，节点右键菜单还提供「拆出当前 Tab」与「拆开所有 Tab」。拆开所有版本时，当前 Tab 保留在原节点，其余版本各自成为独立视频，恢复对应输入连线与参数。合并、拖叠和拆分都支持撤销 / 重做，媒体文件不重写；历史聊天结果仍能定位相应版本。

被分镜或成片引用的视频会优先保留原节点 ID；如果多个视频分别被引用，则保留独立节点以免改错引用。拆出当前版本时，其已有分镜 / 成片引用会跟随拆出的节点。

### 模型准备（在 4090 部署主机运行）

```bash
~/h3engine-venv/bin/python scripts/fetch_editor_models.py
```

脚本将模型放入 `models/`，对 ModelScope 分发的每个文件校验 SHA256，智能选物和自动抠图共用 SAM2，无需额外依赖。可选 `--with-u2net` 安装 U²-Netp 后端，其 ONNX / NumPy 依赖隔离在 `editor-venv`，不会混入 H3 环境。原生重绘使用 SD 1.5 Inpainting；智能选物使用 SAM2.1 Hiera Tiny。模型准备好且引擎空闲时重启引擎，新能力会由 `/api/image-edit/capabilities` 公布。自定义路径可使用 `ONESHOT_EDITOR_MODELS` 和 `ONESHOT_CUTOUT_PYTHON`。

使用参考：[SAM2 官方 Transformers 文档](https://huggingface.co/docs/transformers/model_doc/sam2)、[Diffusers 原生 inpainting 文档](https://huggingface.co/docs/diffusers/using-diffusers/inpaint)、[rembg](https://github.com/danielgatis/rembg)。模型权重各自遵循其模型仓库声明的许可。
