# 剧本工作台回归样本

用 Qwen3.5-9B 在 4090 上对照六个短片片段。每组使用相同原文和创作模型，一稿从原文直接写，一稿增加已确认的大纲。每组交换呈现顺序，先检查原文约束，再比较表演和节奏。样本使用现有项目与内置案例的简短摘编。每组只有一次采样。

| 样本 | 逐场复读 |
| --- | --- |
| 哈文的画市 | 两稿都保留问答和转画顺序。直接写稿在动作栏重复完整台词，确认大纲的稿子把对白集中在对白栏。 |
| 企鹅海战 | 两稿均保留浪打落信号弹、帽子堵漏和无对白。 |
| 草坪上的白西高地 | 两稿都让球落地后再被狗叼起，但动作字段曾留下「放脚边或交到手上」两种落点。提示词已要求只写指定落点。 |
| 三只猫的果茶 | 直接写稿允许猫爸爸在画外或画面边缘剪吸管。确认大纲的稿子明确让猫爸爸剪红吸管，随后小猫喝到果茶。两稿都保留猫妈妈的唯一一句台词。 |
| 清晨手冲 | 两稿都按研磨、注水、尝第一口和杯口蒸汽收尾。 |
| 洱海骑行 | 确认大纲的稿子把白墙青瓦具体写入动作，两个版本都保留了骑行到日落的安静节奏。 |

模型判约束通过时，直接写稿 5/6，确认大纲的稿子 6/6。逐场复读还发现模型放过了对白重复和动作落点不确定的问题。结果用于找回归样本，质量分没有跨样本比较。

在仓库根目录使用 `PYTHONPATH=. python scripts/screenplay_benchmark.py --output /tmp/screenplay-benchmark.json` 可重跑。GPU 被占用时可以加 `--cpu`。JSON 分开记录 A/B 稿件、模型评价和版本对照表，读稿时先看 `comparisons`。
